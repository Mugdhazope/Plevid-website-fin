# PLEVID

Luxury lighting brand website — React + Vite.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Landing page
- `/about` — About Us
- `/products` — Products
- `/projects` — Projects
- `/services` — Services
- `/testimonials` — Testimonials
- `/contact` — Contact
